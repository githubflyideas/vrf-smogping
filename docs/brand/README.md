# Brand assets

The approved vrf-ping logo combines a V-shaped latency trace with slate distribution lines.

- `vrf-ping-icon.svg` / `.png`: standalone mark; PNG is 1024 × 1024.
- `vrf-ping-logo-dark.svg` / `.png`: horizontal logo for dark backgrounds.
- `vrf-ping-logo-light.svg` / `.png`: horizontal logo for light backgrounds.

All assets have transparent backgrounds. Horizontal PNGs are 1360 × 440. Wordmark SVGs retain editable text using Segoe UI, with Helvetica Neue and Arial fallbacks; the icon has no font dependency.

Colors: amber `#f0a838`, slate `#71869d`, dark ink `#17212b`.
